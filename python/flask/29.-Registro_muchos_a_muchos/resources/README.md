# resources/

Aquí debe guardarse el ERD del proyecto (`esquema_educacion_erd.mwb`).

Para generarlo en MySQL Workbench:
1. Ejecuta `flask_app/bd/esquema_educacion.sql`.
2. Database > Reverse Engineer... > selecciona `esquema_educacion`.
3. File > Save Model As... > `esquema_educacion_erd.mwb`.

Se incluye `esquema_educacion_erd.svg` como referencia visual.
