# resources/

Aquí debe guardarse el ERD de la base de datos (`esquema_tacos_erd.mwb`).

Para generarlo en MySQL Workbench:
1. Ejecuta `esquema_tacos.sql`.
2. Database > Reverse Engineer... > selecciona `esquema_tacos`.
3. File > Save Model As... > `esquema_tacos_erd.mwb`.

Se incluye `esquema_tacos_erd.svg` como referencia visual.
