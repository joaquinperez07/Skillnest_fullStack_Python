# resources/

Aquí debe guardarse el ERD del proyecto (`esquema_canciones_erd.mwb`).

Para generarlo en MySQL Workbench:
1. Ejecuta `esquema_canciones.sql` (raíz del proyecto).
2. Database > Reverse Engineer... > selecciona `esquema_canciones`.
3. File > Save Model As... > `esquema_canciones_erd.mwb`.
4. (Opcional) File > Export > Export as PNG > `esquema_canciones_erd.png`.

Se incluye `esquema_canciones_erd.svg` como referencia visual.
