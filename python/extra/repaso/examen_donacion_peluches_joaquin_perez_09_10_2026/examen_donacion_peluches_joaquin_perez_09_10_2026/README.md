# Donación de Peluches

Aplicación Flask (MVC) para registrar usuarios, donar peluches y adoptarlos.

## Instalación local

1. Ejecuta `resources/DB/deploy_local.sql` en MySQL Workbench.
2. Crea un entorno virtual e instala dependencias: `pip install -r requirements.txt`.
3. Edita el archivo `.env` con tu contraseña de MySQL (hay un modelo en `.env.example`).
4. Ejecuta `python run.py` y abre http://localhost:5000
5. El diagrama de la base de datos está en `resources/DB/`.
